# ☕ Nesbah Platform (منصة نسبة)
> Where the love of coffee meets the art of programming. 

Nesbah is a smart web application designed to elevate the specialty coffee brewing experience by replacing randomness with technical precision using pure web technologies.

### 🚀 Key Features
1. **Precision Brewing (Ratios):** Implements exact formulas via JavaScript to calculate water-to-coffee ratios down to the milliliter for a perfect cup every time.
2. **"Rawaq Without Palpitations" (Caffeine Optimization):** A smart feature recommending low-caffeine recipes and extraction methods for users sensitive to caffeine.
3. **Eco-Brew (Sustainability):** Encourages the use of eco-friendly, reusable filters by gamifying the experience with calculated "Eco-Points".

### 🛠️ Tech Stack
* **Structure:** HTML5
* **Styling & Layout:** CSS3 (Responsive Design)
* **Logic & Algorithms:** JavaScript (Vanilla JS)

### 💡 Core Value
Nesbah aligns with Saudi Vision 2030 by promoting health awareness and environmental sustainability through modern technology.
